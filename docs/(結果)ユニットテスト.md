## 本書作成にあたっての対応

`docs/ユニットテスト.md` の精査により、以下の不足・不整合を修正したうえでテストを実装・実行した（詳細はコミット履歴参照）。

1. **U-JK-02/U-JK-03（`confirmJankenRanks`）が未実装だった** → `LEAGUE_TABLE_DATA_DIR` を一時ディレクトリに切り替えてファイルストアを分離する形で単体テストを新規実装（`src/lib/mock-data.test.ts`）。あわせてU-JK-03は「手動確定はファイルストアへの直接書き込みであり、`computeStandings`自体には確定状態を記憶する仕組みがない」という実装の採用仕様をドキュメント側に明記し、`computeStandings`が同一入力に対し常に同じ結果を返す（＝確定状態を保持しない）ことを`ranking.test.ts`側で検証する回帰テストとして実装した。
2. **U-LT-07（`assignCourts`のランダム性契約）の記述が実装と不一致だった** → 「シード固定時は再現可能」という記述に対応するシード指定機能が実装に存在しないため削除し、実際に複数回実行して割当結果が変わりうることを確認する単体テストを新規実装した。
3. **U-MR-09（スコアのデフォルト0とnull/未入力の区別）がどの関数・画面にも対応付けられていなかった** → `ResultInputDialog`の`value={set.scoreA ?? ''}`実装と対応付け、マッピング表に追記した。
4. **U-VAL-17〜19（カテゴリ名25文字・選手(チーム)名10文字・所属10文字の文字数上限）が未採番だった** → 実装（`validateTournamentInput`・`entrant-validation.ts`）に対応する既存テスト（一部ID未ラベル）を正式なテストケースとして採番し、未実装だった所属の文字数上限テスト（U-VAL-19）を新規実装した。
5. **U-MR-02の脚注が存在しないID「U-SET-05」を参照していた** → 「U-MR-09」への参照に修正した（ドキュメント内の誤記）。
6. **U-MR-08の期待結果欄が、マッピング表（結合テストでのみ検証）と矛盾する記述（単体で再計算関数の呼び出しを検証）になっていた** → マッピング表の記述に合わせて修正した。
7. 既存コードに実装済みだがテストケースにID未ラベルだったテスト（U-MO-05/06、U-RF-05/06/07、U-LT-11/12）に、トレーサビリティのためIDラベルを付与した（挙動の変更は無し）。
