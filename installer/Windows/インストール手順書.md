# 「リーグ戦しようよ」インストール手順書（Windows）

## 1. インストーラの入手

本アプリのWindows向けパッケージ（.exe）は、この開発コンテナ（Linux）では生成できないため、GitHub Actionsでビルドしています（`CLAUDE.md`参照）。

1. 以下のURLからビルド結果（ワークフロー実行）を開きます。
   `https://github.com/178722/league-table/actions`
2. バージョンタグ（例：`v1.0.0`）に対応する「Electronデスクトップアプリビルド」の実行を開きます。
3. ページ下部の「Artifacts」から `league-table-windows-latest` をダウンロードします（GitHubアカウントでのログインが必要です）。
4. ダウンロードしたzipを展開すると、`リーグ戦しようよ Setup <バージョン>.exe` が入っています。

> **注意**：GitHub Actionsのアーティファクトは既定で90日間のみ保存されます。長期的に配布する場合は、GitHubの「Releases」機能でこの.exeを正式なリリース資産として添付することを検討してください。

## 2. インストール

1. ダウンロードした `.exe` ファイルをダブルクリックして実行します。
2. インストーラの案内に従って進めます（インストール先フォルダの選択等）。
3. インストール完了後、デスクトップまたはスタートメニューから「リーグ戦しようよ」を起動します。

## 3. 初回起動時の警告について（未署名アプリ）

本アプリはコード署名を行っていないため、初回起動時にWindows Defender SmartScreenが以下のような警告を表示することがあります。

> 「WindowsによってPCが保護されました」

この場合は、以下の手順でインストール・起動を続行してください。

1. 警告画面の「詳細情報」リンクをクリックします。
2. 表示された「実行」ボタンをクリックします。

## 4. アプリの使い方

起動後の操作方法は、同梱の `操作手順書.md` を参照してください。

## 5. データの保存場所

大会データ・バックアップは、Windowsのユーザーデータディレクトリ配下（`%APPDATA%\リーグ戦しようよ\`）に保存されます。アプリをアンインストールしてもこのデータは残ります。
