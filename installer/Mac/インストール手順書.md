# 「リーグ戦しようよ」インストール手順書（macOS）

## 1. インストーラの入手

本アプリのmacOS向けパッケージ（.dmg）は、この開発コンテナ（Linux）では生成できないため、GitHub Actionsでビルドしています（`CLAUDE.md`参照）。

1. 以下のURLからビルド結果（ワークフロー実行）を開きます。
   `https://github.com/178722/league-table/actions`
2. バージョンタグ（例：`v1.0.0`）に対応する「Electronデスクトップアプリビルド」の実行を開きます。
3. ページ下部の「Artifacts」から `league-table-macos-latest` をダウンロードします（GitHubアカウントでのログインが必要です）。
4. ダウンロードしたzipを展開すると、`リーグ戦しようよ-<バージョン>-arm64.dmg` が入っています。

> **注意**：GitHub Actionsのアーティファクトは既定で90日間のみ保存されます。長期的に配布する場合は、GitHubの「Releases」機能でこの.dmgを正式なリリース資産として添付することを検討してください。

## 2. インストール

1. ダウンロードした `.dmg` ファイルをダブルクリックして開きます。
2. 表示されたウィンドウ内の「リーグ戦しようよ」アイコンを「Applications」フォルダへドラッグ＆ドロップします。
3. Launchpad または「Applications」フォルダから「リーグ戦しようよ」を起動します。

## 3. 初回起動時の警告について（未署名アプリ）

本アプリは開発者証明書による署名を行っていないため、初回起動時にmacOSのGatekeeperが以下のような警告を表示することがあります。

> 「"リーグ戦しようよ"は、開発元が未確認のため開けません。」

この場合は、以下の手順で起動してください（**手順1を行わずにいきなり「システム設定」を開いても、「このまま開く」ボタンは表示されません**。一度起動を試みて拒否された直後でないと表示されないため、必ず1→2の順で行ってください）。

1. 「Applications」フォルダの「リーグ戦しようよ」をダブルクリックして起動を試みます（上記の警告が出るので「完了」または「キャンセル」で閉じます）。
2. 続けて「システム設定」→「プライバシーとセキュリティ」を開きます。**この操作は手順1の直後（目安として1時間以内）に行ってください。時間が経つとボタンが消え、手順1からやり直しが必要になります。**
3. 画面下部（セキュリティ欄）に「"リーグ戦しようよ"は開発元が未確認のため、使用がブロックされました。」という表示があるので、「このまま開く」ボタンをクリックします。
4. 管理者パスワード（またはTouch ID）の入力を求められたら入力し、確認ダイアログで「開く」を選択します。

> **注意（macOS Sequoia 15以降）**：以前案内していた「Finderでアプリを右クリック（control+クリック）→「開く」」という回避方法は、macOS Sequoia（15）以降では廃止されており使用できません。必ず上記1〜4の手順で起動してください。

**上記の「このまま開く」ボタンがどうしても表示されない場合**は、代わりに「ターミナル」アプリを開き、以下のコマンドを実行してから再度起動してください（macOSのバージョンに依存せず有効な方法です）。

```
xattr -cr "/Applications/リーグ戦しようよ.app"
```

## 4. アプリの使い方

起動後の操作方法は、同梱の `操作手順書.md` を参照してください。

## 5. データの保存場所

大会データ・バックアップは、同じPCの複数ユーザーアカウント間で共有できるよう、マシン単位の共有ディレクトリ（`/Library/Application Support/リーグ戦しようよ/`）に保存されます。アプリをアンインストールしてもこのデータは残ります。

> **注意**：このディレクトリは管理者グループのみ書き込み可能なため、**複数のmacユーザーアカウントで使う場合、最初にアプリを起動するのは管理者権限のあるアカウントで行ってください**。非管理者（標準）アカウントで最初に起動すると、共有フォルダの作成に失敗しアプリが起動できません。
